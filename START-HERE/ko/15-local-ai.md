# 15. 성능 좋은 컴퓨터에서 돌리는 로컬 AI(선택, 고급)

> 영어 원문(전체 안내서): [../15-local-ai.md](../15-local-ai.md)

## 짧은 버전
*다 읽을 시간이 없나요? 짧은 버전이에요. 전체 안내서는 아래 링크(영어)에 있어요.*

- 선택이고 고급이에요: 정원의 AI 상자에 쓰는 AI를 집의 성능 좋은 컴퓨터에서 Ollama로 돌려요. 비공개이고, 한 번 설정하면 무료예요.
- 정원 노트북에서는 안 돼요: 성능 좋은 그래픽 카드(그래픽 메모리 8 GB 이상이면 넉넉해요)나 Apple Silicon Mac이 필요해요.
- <https://ollama.com/download>에서 Ollama를 설치하고, `ollama pull phi4`.
- 정원 컴퓨터만 들어올 수 있게 하세요(3단계).
- 정원 연결하기: 메뉴 `M`, 그다음 `9`, 그리고 AI 컴퓨터의 주소를 입력하세요. 끄려면 다시 실행하고 주소를 비워 두세요.
- 공유기에서 포트 11434를 절대 전달하지 마세요. 로컬 AI는 집 안에서만 써요.
- AI 컴퓨터가 꺼져 있으면 AI 상자는 조용히 있어요. 정원의 나머지는 영향을 받지 않아요.

## 로컬 식물 AI: 새 식물을 채우는 데스크톱 도우미
로컬 AI의 두 번째, 따로 쓰는 용도예요. 식물 관리 화면의 **식물 추가** 탭에서 속, 종, 이름, 화단,
수량, 가격만 입력하면, Windows PC의 도우미가 재배 회사의 페이지와 믿을 만한 정원 페이지에서 나머지를
채우고, 모든 값을 확인하고, 사진을 5장까지 찾아요. 그다음 무엇이 채워졌는지, 무엇을 확인해야 하는지,
무엇이 아직 비어 있는지 보고 **승인**을 눌러요 (정원 주인만 할 수 있어요).

- **Windows PC 전용, 그래픽 메모리 12GB 이상의 NVIDIA 카드** (예: RTX 4070 Ti). Windows 설치
  마법사는 그런 PC에서만 이것을 보여 주고 (CUSTOM, '로컬 식물 AI'), 다른 PC에서는 그 이유를 말해요.
  나중에: Windows 메뉴, More, 22.
- **Linux 설치 프로그램(garden.sh)은 AI 모델을 절대 설치하지 않아요.** Windows와 Ubuntu 설치
  프로그램이 다르게 하는 단 하나예요: 정원 노트북에는 그럴 그래픽 카드가 없어요.
- PC에 설치되는 것: Ollama(Windows와 함께 시작하고 그 PC 안에서만, 127.0.0.1에서 응답하는 백그라운드
  작업), 정보를 채우는 `phi4`와 그것과 사진을 확인하는 `gemma4:12b` 모델(한 번에 하나만), Python,
  그리고 도우미(`plant-ai/`).
- **어디에도 새로 여는 포트가 없어요.** 웹사이트가 대기열을 가지고 있어요. 도우미는 1분마다 웹사이트의
  평소 주소로 (브라우저처럼 밖으로만) 자기 키를 가지고, 집 네트워크에서만 일을 물어봐요. 웹사이트는
  다른 컴퓨터(노트북)에서 돌아가도 돼요. PC가 꺼져 있을 때 추가한 식물은 대기열에서 기다려요.
- 키: 웹사이트에서 식물 추가, 데스크톱 도우미, **도우미 키 만들기** (한 번만 보여요). 마법사의 로컬
  식물 AI 페이지나 Windows 메뉴 More, 22에 붙여 넣으세요.
- AI는 **빈** 칸만 채우고 있는 값은 절대 바꾸지 않아요. 바꾸기 전마다 식물의 사본을 남겨요. 사진은 한
  장마다 `.webp` 파일 하나(500~2000px)이고, 작은 사본은 만들지 않아요.
- AI가 찾지 못한 것: **아직 비어 있는 것 내보내기**는 빈 칸, 허용되는 값, 내 Claude에게 줄 프롬프트가
  담긴 작은 파일을 줘요. 답은 고급, JSON Pipeline, 가져오기로 넣어요 (먼저 모든 값을 보여 줘요).
