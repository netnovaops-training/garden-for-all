# 10. 계획: 확인 지점이 있는 조심스러운 순서

> 영어 원문(전체 안내서): [../10-the-plan.md](../10-the-plan.md)

## 짧은 버전
*다 읽을 시간이 없나요? 짧은 버전이에요. 전체 안내서는 아래 링크(영어)에 있어요.*

- 안내서를 하는 조심스러운 순서예요. 단계마다 확인 지점이 있어요. "세션" 하나는 약 2~3시간이에요.
- 기초부터 만들고, 층마다 작동하는지 확인하세요. 작동하지 않는 것 위에 새것을 올리지 마세요.
- 시작하기 전에(15분): 안내서 00을 읽고, 메모 파일 `lab-notes.txt`를 만들고, 비밀번호 관리자를 준비하세요.
- 세션 1: Ubuntu를 설치한 다음 첫 시작을 해요. 압축을 푼 폴더에서 `Start-Here-Ubuntu.sh`를 오른쪽 클릭하고 **Run as a Program**을 고르세요(또는 `bash Start-Here-Ubuntu.sh`). 처음에는 GitHub에서 프로그램을 받아 파일을 하나하나 확인해요. `garden.sh`와 `lab/`은 이때 생기므로, `lab/` 명령은 첫 시작 뒤에만 돼요. 설치(메뉴 `1`)는 세션 2에서 해요. 확인: `bash lab/09-health-check.sh`가 오류 메시지 없이 돌고, 노트북을 다시 켜도 잘 돌아와야 해요. 아직 아무것도 설치하지 않았으니 Docker(1번), 서비스(2번), 포트(3번), 설정 파일(4번)에 빨간 FAIL이 보이는 것은 정상이고, 5번은 "No backups yet"이라고 말해요. 세션 2가 끝나면 초록색이 돼요.
- 순서: Ubuntu, 그다음 Docker와 내 정원, Uptime Kuma와 백업, Gemini, Home Assistant, n8n 이메일, 센서와 물 주기, 웹사이트의 측정값, 그리고 마지막으로 인터넷.
- 인터넷 단계(세션 14~16): 먼저 테스트 이름으로 연습하고(안내서 04, C 부분), 그다음 안내서 [23](23-full-setup.md)의 9~11 부분으로 진짜로 해요.
- 물 주기: 밸브는 물에 닿기 전에 탁자 위에서 물 없이 작동해야 해요. 물 없는 테스트는 절대 건너뛰지 마세요.
- 매주(15분): `bash lab/09-health-check.sh`, Ubuntu 업데이트, 그리고 `backups/`를 USB 스틱에 복사하기.
