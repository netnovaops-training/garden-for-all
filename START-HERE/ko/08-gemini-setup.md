# 08. Gemini를 실험실 도우미로 설정하기

## 짧은 버전
*다 읽을 시간이 없나요? 짧은 버전이에요. 전체 안내서는 아래 링크(영어)에 있어요.*

- Gemini를 도우미로 설정하는 세 가지 방법: A, Gemini 웹사이트에 저장한 "Gem"(10분). B, 프로젝트 폴더의 Gemini CLI(30분). C, 웹사이트 AI 상자용 무료 키(10분).
- A부터 시작하세요. Gemini가 실제 파일을 보기를 원할 때 B를 더하세요.
- Gemini CLI에는 Node.js 20 이상이 필요해요. `npm install -g @google/gemini-cli`로 설치하고, 프로젝트 폴더 안에서 `gemini`를 입력하세요.
- Gemini에게 비밀 정보를 절대 주지 마세요: 비밀번호, 키, `.env` 파일 모두 안 돼요. Gemini CLI가 `.env`를 읽게 하지 마세요.
- Gemini는 틀릴 수 있어요. 말하는 것을 안내서와 비교하고, 명령은 한 번에 하나만 실행하세요.
- 막혔나요? `bash lab/10-collect-for-gemini.sh`가 비밀번호와 키를 뺀 정보 파일을 만들어요. 읽어 보고, "I am stuck"(막혔어요) 질문과 함께 붙여 넣으세요.
