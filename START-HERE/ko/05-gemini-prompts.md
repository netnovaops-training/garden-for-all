# 05. 복사해서 쓰는 Gemini 질문

> 영어 원문(전체 안내서): [../05-gemini-prompts.md](../05-gemini-prompts.md)

## 짧은 버전
*다 읽을 시간이 없나요? 짧은 버전이에요. 전체 안내서는 아래 링크(영어)에 있어요.*

- Gemini(gemini.google.com 또는 Gemini CLI)에 쓰는 시작 질문이에요. 하나를 복사하고, 대문자로 된 말을 바꾸고, 붙여 넣으세요.
- 새 채팅마다 질문 1(context block, 배경 설명)을 가장 먼저 붙여 넣으세요.
- 질문 2는 명령을 실행하기 전에 설명해 달라고 해요. 질문 3은 막혔을 때 써요.
- 전기나 물과 관련된 일 전에는 질문 6("Check my plan", 내 계획 확인하기)을 쓰세요.
- 비밀번호, 앱 비밀번호, API 키, `.env` 파일은 어떤 AI 채팅에도 절대 넣지 마세요. 파일을 붙여 넣기 전에 비밀 정보가 없는지 확인하세요.
- Gemini CLI는 프로젝트 폴더의 `GEMINI.md`를 스스로 읽어요.
