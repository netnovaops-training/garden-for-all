# 11. 웹사이트가 작동하는 방법과 안전하게 바꾸는 방법

> 영어 원문(전체 안내서): [../11-maintain-your-site.md](../11-maintain-your-site.md)

## 짧은 버전
*다 읽을 시간이 없나요? 짧은 버전이에요. 전체 안내서는 아래 링크(영어)에 있어요.*

- 방문이 정원 안을 어떻게 지나가는지, 파일 종류마다 어디에 있는지, 그리고 안전하게 바꾸는 방법이에요.
- `site/`의 파일(스타일, 스크립트)은 다시 빌드할 필요가 없어요: 저장하고, `Ctrl+Shift+R`로 페이지를 새로 고치세요.
- Rust 파일과 페이지 템플릿은 다시 빌드해야 해요: 메뉴 `M`, 그다음 `7`.
- 언제나 안전한 방법: 백업(메뉴 `6`), 하나만 바꾸기, 필요하면 다시 빌드, 테스트(메뉴 `5`), 그다음 그대로 두거나 되돌리기.
- `git diff`가 바꾼 것을 정확히 보여 줘요. `git checkout -- FILE`로 되돌려요.
- 설정과 비밀번호는 `.env`에 있어요: 메뉴 `8`로 바꾸세요. `.env`나 비밀번호를 Gemini에 절대 붙여 넣지 마세요.
