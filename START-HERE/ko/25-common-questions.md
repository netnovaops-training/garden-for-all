## 짧은 버전
*사람들이 가장 많이 묻는 질문에 짧게 답해요. 답마다 어떤 메뉴 키를 누르면 되는지 알려 줘요.*

**매일**
- 정전이나 다시 시작한 뒤에 정원이 저절로 켜지나요?
- 컴퓨터를 꺼도 되나요?
- 노트북 덮개를 닫으면 어떻게 되나요?
- 잘 돌아가는지 어떻게 알아요?
- 내 웹 주소는 어디에 있나요?
- Windows: PC를 계속 켜 둬야 하나요?
- 한동안 정원을 꺼 둘 수 있나요?

**비밀번호와 사람**
- 웹사이트 비밀번호를 잊어버렸어요.
- Ubuntu 비밀번호를 잊어버렸어요.
- 친구가 편집할 수 있나요, 아니면 보기만 하나요?
- 누가 내 정원을 볼 수 있나요?
- 이제 접근하면 안 되는 사람이 있어요.
- 비밀번호와 키는 어디에 보관되나요?
- 웹사이트만의 Gmail이 있으면 좋나요?
- 비밀번호나 키를 실수로 어딘가에 붙여 넣었어요.

**무언가 잘못됐을 때**
- 실수했어요. 어떻게 되돌려요?
- 사진이 없어졌어요.
- AI 상자가 대답하지 않아요.
- 웹 이름이 작동하지 않아요.
- 디스크가 차고 있나요?
- 로그는 어디에 있나요?
- 비밀번호를 보여 주지 않고 도움을 받으려면요?

**바꾸기와 업데이트**
- 컴퓨터는 어떻게 업데이트해요?
- 정원 프로그램은 어떻게 업데이트해요?
- 휴대폰 앱은 어떻게 업데이트돼요?

**옮기기와 지우기**
- 정원을 새 컴퓨터로 어떻게 옮겨요?
- 폴더와 페이지에 내 이름을 붙일 수 있나요?
- 어떻게 지워요(제거해요)?

**Windows와 Docker**
- 이미 Docker Desktop을 써요. 문제가 되나요?
- 오래된 Windows 7 PC가 있어요. 쓸 수 있나요?
- 다른 사람도 이걸로 자기 정원을 시작할 수 있나요?

## 매일

### 정전이나 다시 시작한 뒤에 정원이 저절로 켜지나요?
네, Ubuntu가 다시 켜지면요(컴퓨터 자체가 꺼졌다면 전원 버튼을 누르세요). 그러면
Docker가 정원을 저절로 켜요. 아무도 로그인하지 않아도 되고, 정문(Caddy)과 No-IP
업데이트 프로그램도 같이 켜져요. 하나만 예외예요: 메뉴 `3`으로 정원을 멈췄다면,
다시 켤 때까지 멈춘 채로 있어요.

**누를 키:** 메뉴 `2`로 켜요. 메뉴 `5`로 확인해요.
**더 보기:** [안내서 19](19-every-menu-option.md)(메뉴 2와 3)

### 컴퓨터를 꺼도 되나요?
네, 잃어버리는 건 없어요. 꺼져 있는 동안에는 아무도 정원을 열 수 없고, 자동
백업도 하지 않아요(다시 켠 뒤 처음 살펴볼 때 따라잡아요). 평소처럼 끄세요: Ubuntu 오른쪽 위 메뉴에서
**Power Off**(전원 끄기).

**더 보기:** [안내서 13](13-backups-and-folders.md)(자동 백업 일정)

### 노트북 덮개를 닫으면 어떻게 되나요?
보통은 Ubuntu가 잠들고, 정원도 멈춰요. 안내서 01의 24단계와 25단계를 하면
덮개를 닫아도 노트북이 깨어 있어요. 덮개를 닫은 노트북은 뜨거워져요: 덮개를
조금 열어 두세요.

**더 보기:** [안내서 01](01-ubuntu-laptop.md)(G 부분)

### 잘 돌아가는지 어떻게 알아요?
점검표를 실행하세요. 줄마다 **PASS**(좋아요), **WARN**(곧 고치세요),
**FAIL**(먼저 고치세요)이라고 나오고, 고치는 방법이 바로 아래에 있어요.
마지막 줄이 개수를 세어 줘요: `0 fail`이 나오면 돼요.

**누를 키:** 메뉴 `5`(또는 `bash garden.sh check`). `CHECKLIST.txt`에도 저장돼요.
**더 보기:** [안내서 09](09-troubleshooting.md)

### 내 웹 주소는 어디에 있나요?
메뉴 `A`가 정원의 모든 주소와, 어떤 주소에 로그인이 필요한지 보여 줘요.
정원 폴더의 `MY-ADDRESSES.txt`에도 저장해요.

**누를 키:** 메뉴 `A`
**더 보기:** [안내서 23](23-full-setup.md)(15 부분)

### Windows: PC를 계속 켜 둬야 하나요?
네. Windows에서는 정원이 Windows 안의 Ubuntu(WSL)에서 돌아가서, PC가 꺼지거나
잠들면 멈춰요. **Settings, System, Power, Sleep**(설정, 시스템, 전원, 절전)을
**Never**(안 함)로 하세요. 다시 시작한 뒤에는 Windows에 로그인하세요: 설치할 때
"Jun's Garden keep running" 작업에 예라고 했다면 그 작업이 정원을 다시 켜요.
아니라면 Windows 메뉴 `2`를 쓰세요.

**더 보기:** [안내서 00b](00b-before-you-start.md)

---

### 한동안 정원을 꺼 둘 수 있나요?
네. 메뉴 `M`, 그다음 `14`, 그다음 `1`(모두 끄기). 모든 프로그램과 현관문을 멈추고,
아무것도 지우지 않아요: 식물, 사진, 데이터, 캐시, 백업, 설정은 폴더에 그대로 있어요.
한동안 사이트를 운영하고 싶지 않을 때나 접속이 너무 많을 때 쓰세요. 메뉴 `M`, `14`,
그다음 `2`가 몇 달 뒤에도 모두 다시 켜고 웹사이트를 확인해요. 꺼져 있는 동안에도
무료 No-IP 이름은 30일마다 계속 확인하세요.

**누를 키:** 메뉴 `M`, 그다음 `14`
**더 보기:** [안내서 26](26-rename-move-and-switch.md)(켜기 / 끄기 스위치)

## 비밀번호와 사람

### 웹사이트 비밀번호를 잊어버렸어요.
로그인 페이지에서 **Forgot password? / First time?**(비밀번호를 잊으셨나요? /
처음인가요?)을 누르면 웹사이트가 링크를 이메일로 보내 줘요. 이메일이 설정되어
있을 때만 돼요(메뉴 `8`, 그다음 `3`). 아니면 정원 컴퓨터에서 새 비밀번호를
정하세요: 메뉴 `U`, 그다음 `5`. 입력하는 동안 아무것도 안 보여요. 정상이에요.

**더 보기:** [안내서 07](07-sso-gate.md)

### Ubuntu 비밀번호를 잊어버렸어요.
Ubuntu는 새 비밀번호를 이메일로 보내 줄 수 없어요. Ubuntu 공식 페이지에 나온
대로 복구 모드로 켜세요: <https://wiki.ubuntu.com/RecoveryMode>
(켜지는 동안 `Shift`를 누르고 있거나 `Esc`를 누르세요. **Advanced options**(고급
옵션), 그다음 **(recovery mode)**(복구 모드)로 끝나는 줄, 그다음 **Drop to root
shell prompt**(루트 셸 프롬프트로 들어가기)를 고르세요.) 그다음 아래를 한 줄씩
입력하세요. `jun` 대신 내 사용자 이름을 쓰세요:

```
mount -o remount,rw /
passwd jun
reboot
```

**더 보기:** [안내서 01](01-ubuntu-laptop.md)(내 계정), [안내서 22](../22-bash-walkthrough.md)(sudo와 비밀번호, 영어)

### 친구가 편집할 수 있나요, 아니면 보기만 하나요?
정원이 인터넷에 올라가 있으면 누구나 볼 수 있어요. 계정은 필요 없어요. 친구가
**편집**하게 하려면 메뉴 `U`, 그다음 `2`를 쓰고, 첫 비밀번호는 직접 만나서
알려 주세요. **게스트**(메뉴 `U`, 그다음 `3`)는 로그인 페이지에 로그인만 할 수
있어요: 편집도, 정원 도구도 안 돼요. 게스트는 정문이 먼저 있어야 해요(메뉴 `M`,
그다음 `1`).

**더 보기:** [안내서 07](07-sso-gate.md), [안내서 23](23-full-setup.md)(12 부분)

### 누가 내 정원을 볼 수 있나요?
정문을 만들기 전에는 정원 컴퓨터만 볼 수 있어요. 인터넷에 올라가면 누구나
웹사이트를 볼 수 있어요: 식물 카탈로그, 갤러리, 블로그. 편집은 사용자 목록에 있는
사람만 할 수 있고, 정원 도구(`/beds`)는 로그인한 뒤에만 열려요.

**누를 키:** 메뉴 `U`, 그다음 `1`이 로그인할 수 있는 사람을 보여 줘요.
**더 보기:** [안내서 07](07-sso-gate.md)

### 이제 접근하면 안 되는 사람이 있어요.
메뉴 `U`, 그다음 `4`가 그 사람의 모든 로그인을 지워요. 메뉴 `U`, 그다음 `8`
(LOCK DOWN, 잠그기)은 나만 남겨요: 새 비밀번호를 만들고, 모두 로그아웃돼요.

**더 보기:** [안내서 19](19-every-menu-option.md)(사용자와 접근 권한)

### 웹사이트만의 Gmail이 있으면 좋나요?
좋은 생각이고 무료예요: <https://accounts.google.com/signup>. 웹사이트의 이메일(메뉴 `M`, `3`),
Google Drive 백업, AI 키에 쓰고, "Sign in with Google"로 Tailscale, DuckDNS, No-IP에
로그인하세요. 개인 메일함은 따로 지켜지고, 언젠가 웹사이트를 넘겨줄 때 계정 하나만 넘기면
돼요. 그 계정의 2단계 인증을 켜세요. 정원 자체의 로그인은 내 정원 비밀번호 그대로예요:
바깥 계정으로는 정원을 열 수 없어요.

Gmail 하나로 서비스마다 다른 주소(`name+noip@gmail.com`)를 줄 수도 있어서, 누가 무엇을 보내는지
보여요: 안내서 00b, "내 웹사이트의 이름과 이메일 정하기".

**더 보기:** [안내서 00b](00b-before-you-start.md)

### 비밀번호와 키는 어디에 보관되나요?
정원 폴더 안의 비공개 파일 하나, `.env`에 있어요. 나만 읽을 수 있어요. 메뉴는
비밀번호나 키를 절대 보여 주지 않고, "set"(설정됨)이나 "not set"(설정 안 됨)만
알려 줘요. 채팅, 이메일, AI 채팅에 절대 붙여 넣지 마세요.

**누를 키:** 키는 메뉴 `K`, 내 비밀번호는 메뉴 `U`, 그다음 `5`.
**더 보기:** [안내서 00](00-READ-ME-FIRST.md)(규칙 2)

### 비밀번호나 키를 실수로 어딘가에 붙여 넣었어요.
지금 바꾸세요. 내 비밀번호: 메뉴 `U`, 그다음 `5`. 키: 메뉴 `K`, 그 키를 고르고,
`1`을 눌러 새 키를 붙여 넣으세요. 그다음 그 서비스의 웹사이트에서 옛 키를
지우세요.

**더 보기:** [안내서 09](09-troubleshooting.md)(안전 문제)

## 무언가 잘못됐을 때

### 실수했어요. 어떻게 되돌려요?
백업을 되돌려 놓으세요: 메뉴 `7`, 그다음 하나를 고르세요(가장 새것이 맨 위에
있어요). 무엇이든 바꾸기 전에, 지금 있는 것을 `before-restore` 백업으로 먼저
저장해요. 모든 것이 그 백업의 시간으로 돌아가요. 마음이 바뀌었나요? 메뉴 `7`을
다시 하고 `before-restore` 백업을 고르세요.

**누를 키:** 메뉴 `7`
**더 보기:** [안내서 13](13-backups-and-folders.md)

### 사진이 없어졌어요.
사진은 따로 받는 파일이에요: `junsgarden-photos-addon.zip`. 압축을 풀지 말고 홈,
다운로드, 바탕화면 폴더 중 하나에 두고, 메뉴 `6`, 그다음 `11`을 고르세요. 이미 있는
사진은 그대로 둬요. 내가 직접 올렸다가 없어진 사진은 백업으로 돌아와요(메뉴 `7`).

**누를 키:** 메뉴 `6`, 그다음 `11`
**더 보기:** [안내서 13](13-backups-and-folders.md)

### AI 상자가 대답하지 않아요.
키를 테스트하세요: 메뉴 `K`, 그다음 `1`(Gemini), 그다음 `2`(테스트). 키가 틀렸다고
나오면 `1`을 고르고 다시 붙여 넣으세요. 무료 한도를 다 썼다고 나오면 내일 다시
채워져요. 무료 OpenRouter 키는 바쁠 때를 위한 예비예요: 메뉴 `K`, 그다음 `2`,
그다음 `1`.

**더 보기:** [안내서 16](16-ai-studio.md)

### 웹 이름이 작동하지 않아요.
무료 No-IP 이름은 30일마다 확인해야 해요: No-IP가 링크를 이메일로 보내 주면
**Confirm**(확인)을 누르세요(스팸함도 보세요). 그다음 점검표를 실행하세요(메뉴
`5`): No-IP 업데이트 프로그램이 돌아가는지, 이름이 우리 집을 가리키는지 보여 줘요.
업데이트 프로그램이 멈춰 있다면: 메뉴 `K`, 그다음 `N`.

**더 보기:** [안내서 09](09-troubleshooting.md)(인터넷 쪽), [안내서 04](04-go-public-no-ip-caddy.md)

### 디스크가 차고 있나요?
점검표의 마지막 확인이 "Disk is ...% full"(디스크가 ...% 찼어요)이라고 알려 줘요:
85% 아래면 PASS, 85%부터 FAIL이에요. 자동 백업은 저절로 솎아 내요(오늘 것은 최신 3개, 그다음 일주일은 하루에 하나). 내가
직접 만든 백업은 저절로 지워지지 않고, 하나가 약 800 MB예요. 공간을 비우려면 내
옛 백업을 USB에 복사하고, `backups/`에서 지운 다음, 정리를 쓰세요: 메뉴 `M`, `14`,
그다음 `5`. Docker의 남은 것(7일이 넘은 정원 프로그램의 옛 버전)만 지우고, 먼저 물어봐요.

**누를 키:** 메뉴 `5`, 그리고 메뉴 `M`, 그다음 `14`
**더 보기:** [안내서 13](13-backups-and-folders.md), [안내서 09](09-troubleshooting.md), [안내서 26](26-rename-move-and-switch.md)

### 로그는 어디에 있나요?
정원 프로그램들의 최근 메시지: 메뉴 `M`, 그다음 `6`. 설치와 정문은 보여 주는 모든
것을 `logs/` 폴더에 저장해요(`logs/install-progress.txt`가 설치가 멈춘 곳을 보여
줘요). 밤 백업은 `backups/backup.log`에 기록해요.

**누를 키:** 메뉴 `M`, 그다음 `6`
**더 보기:** [안내서 09](09-troubleshooting.md)(로그 보기)

### 비밀번호를 보여 주지 않고 도움을 받으려면요?
메뉴 `H`가 `help/` 폴더에 도움 파일을 만들어요. 비밀번호와 키는 빼고 만들어요.
먼저 읽어 보세요(그냥 글자 파일이에요). 그다음 도와주는 사람에게 보내거나 Gemini에
붙여 넣으세요.

**누를 키:** 메뉴 `H`
**더 보기:** [안내서 09](09-troubleshooting.md), [안내서 05](05-gemini-prompts.md)

## 바꾸기와 업데이트

### 컴퓨터는 어떻게 업데이트해요?
일주일에 한 번, 터미널에서:

```
sudo apt update && sudo apt upgrade -y
```

이렇게 하면 Docker와 Caddy도 업데이트돼요. 둘 다 만든 곳의 Ubuntu 공급처에서 왔기
때문이에요. Ubuntu가 다시 시작하라고 하면 `sudo reboot`를 입력하세요. 정원은
저절로 다시 켜져요.

**더 보기:** [안내서 01](01-ubuntu-laptop.md)(E 부분), [안내서 22](../22-bash-walkthrough.md)(sudo, 영어)

### 정원 프로그램은 어떻게 업데이트해요?
메뉴에는 정원 프로그램을 업데이트하는 버튼이 없어요. 메뉴 `1`은 망가진 것을
고치지만, 이미 잘 돌아가는 것은 건너뛰어서 새 버전을 받아 오지 않아요. 직접 하려면:
먼저 백업하고(메뉴 `6`, 그다음 `1`), 정원 폴더에서 아래 줄을 입력하세요. 미리 만들어진
프로그램(데이터베이스, 위키, 로그인 페이지)의 새 복사본을 받아 와요. 그다음 메뉴
`2`가 새 복사본을 켜요.

```
docker compose pull --ignore-buildable
```

**더 보기:** [안내서 02](02-docker.md)(Docker 명령)

### 휴대폰 앱은 어떻게 업데이트돼요?
앱은 열릴 때마다 내 웹사이트에 더 새로운 앱이 있는지 물어봐요(파일
`site/apps/version.json`). 있으면 업데이트를 권하고, 설치하기 전에 Android가 먼저
물어봐요. 더 새로운 앱은 내가 직접 만들어서 올렸을 때만 거기에 생겨요.

**더 보기:** [안내서 17](17-android-app-and-ai-coding.md)

## 옮기기와 지우기

### 정원을 새 컴퓨터로 어떻게 옮겨요?
새 컴퓨터에 정원을 설치하세요(메뉴 `1`). 가장 새 백업을 그 컴퓨터의 `backups/`
폴더에 복사하고, 메뉴 `7`에서 그 백업을 고르세요. 키와 이메일 비밀번호는 백업에
들어 있지 않아요: 메뉴 `K`와 메뉴 `8`, 그다음 `3`으로 다시 넣으세요. 거기서 인터넷에
올리려면: 메뉴 `M`, 그다음 `1`, 그리고 공유기가 새 컴퓨터를 가리키게 하세요(안내서 14).

**더 보기:** [안내서 13](13-backups-and-folders.md)(새 컴퓨터로 옮기기), [안내서 14](14-reserve-your-ip.md)

### 폴더와 페이지에 내 이름을 붙일 수 있나요?
네, 메뉴 `M`, 그다음 `18`로요. 손으로 바꾸지는 마세요: 코드와 데이터베이스가 아직 옛
이름을 써서 페이지가 망가져요. 메뉴는 파일이나 폴더의 이름과 그것을 쓰는 모든 곳을
함께 바꾸고, 먼저 모두 보여 주고, 백업도 해요. 알아 둘 것 하나: 안내서에는 계속 정원이
처음 가진 이름이 나와요. `logs/renames.tsv`에 지금 무엇이 무엇으로 불리는지 적혀
있어요(메뉴 `M`, `18`, 그다음 `4`). 정원 폴더 전체를 더 큰 디스크로 옮기는 것도 같은
메뉴에 있어요(`3`).

**누를 키:** 메뉴 `M`, 그다음 `18`
**더 보기:** [안내서 26](26-rename-move-and-switch.md)

### 어떻게 지워요(제거해요)?
메뉴 `M`, 그다음 `12`. 선택 `1`은 프로그램만 지우고 정원(사진, 데이터베이스, 백업)은
남겨요. 메뉴 `1`로 다시 설치할 수 있어요. 선택 `2`는 모두 지우지만, 먼저 마지막 백업을
만들고 `DELETE`를 입력하라고 해요.

**더 보기:** [안내서 19](19-every-menu-option.md)(제거)

## Windows와 Docker

### 이미 Docker Desktop을 써요. 문제가 되나요?
아니요. 이 PC에 설치하면 설치 프로그램이 어떤 Docker를 쓸지 물어요. Docker Desktop은
쉬운 방법이에요: 정원의 프로그램이 그 창에 버튼과 함께 보여요. Ubuntu 안의 Docker는
직접 하는 방법이에요. 직접 하는 방법을 골랐다면, `JunsGarden`의 Docker Desktop WSL
integration은 꺼 두세요(Docker Desktop > Settings > Resources > WSL integration).
켜져 있으면 점검표가 알려 줘요. 정리는 다른 Docker 프로젝트의 이미지를 절대 건드리지 않아요.

**더 보기:** [안내서 26](26-rename-move-and-switch.md)(Windows에서: Docker를 돌리는 두 가지 방법)

### 오래된 Windows 7 PC가 있어요. 쓸 수 있나요?
정원에는 안 돼요. Windows 7은 2020년 1월부터 보안 업데이트가 없어서 인터넷에 웹사이트를
열기에 안전하지 않고, WSL과 최신 Docker도 없어요. 대신 그 오래된 노트북에 Ubuntu를
설치하거나(먼저 파일을 USB 메모리에 복사하세요), 정원은 다른 컴퓨터에서 돌리고 오래된
PC로는 보기만 하세요.

**더 보기:** [안내서 26](26-rename-move-and-switch.md), [안내서 01](01-ubuntu-laptop.md)

### 다른 사람도 이걸로 자기 정원을 시작할 수 있나요?
네: 코드는 공개되어 있고 자유롭게 쓸 수 있어요(MIT 라이선스). 내 정원의 데이터가 없으면
설치 프로그램은 빈 정원을 만들어요. 새로 시작하는 사람을 위한 시작 정원(그 지역에 맞는
자유롭게 쓸 수 있는 식물과 자기 사진)은 나중 버전을 위한 생각이에요. 이번 버전에는 없어요.

**더 보기:** [안내서 18](18-review-the-code.md)(공개 코드)
