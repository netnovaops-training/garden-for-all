# 03. 집에서 정원 쓰기: 비밀번호, 이메일, AI, 첫 편집

> 영어 원문: [../03-run-your-garden.md](../03-run-your-garden.md)

## 짧은 버전
*다 읽을 시간이 없나요? 짧은 버전이에요. 전체 안내서는 아래에 있어요.*

- 이 안내서는 집에서 `http://localhost:8030`으로 정원을 쓰게 해 줘요: 비밀번호, 이메일, AI 상자, 첫 편집.
- 설치가 끝난 뒤 30분 걸려요. 무료예요.
- 정원 열기: 메뉴 `4`.
- 비밀번호 정하기: 메뉴 `U`, 그다음 `5`(10자 이상).
- "비밀번호 찾기" 링크용 이메일(선택): Gmail 앱 비밀번호를 만들고, 메뉴 `8`, 그다음 `3`.
- AI 상자(선택): <https://aistudio.google.com/apikey>에서 무료 키를 만들고, 메뉴 `8`, `4`, `1`(Gemini), 그다음 다시 `1`(Paste a new key, 새 키 붙여 넣기).
- `http://localhost:8030/login.php`에서 로그인하고, 식물 관리(`/streamlit/`)에서 식물 하나를 바꿔 보세요. (Windows에서 따로 있는 정원 컴퓨터를 쓰면: Windows 메뉴 `4`, 그다음 열린 주소 끝에 `/login.php`를 붙이세요.)
- 시간대: 설치는 그 컴퓨터 자신의 시간대를 써요. 바꾸려면: 메뉴 `8`, 그다음 `2`.
- 점검표(메뉴 `5`)가 0 fail(실패 0개)로 끝나면 잘 된 거예요.

---

## 무엇을 만드나요
정원 컴퓨터의 `http://localhost:8030`에서 돌아가는 내 정원. 식물과 사진이 모두 있고(사진은 따로 받는 파일에서 와요: 메뉴 `6`, 그다음 `11`),
내 비밀번호, "비밀번호 찾기" 링크용 이메일, 그리고 작동하는 AI 상자까지요.

## 시간과 비용
설치가 끝난 뒤 30분. 무료예요.

## 먼저 필요한 것
설치가 끝나 있어야 해요(메뉴 `1`이 **ALL DONE**(모두 끝났어요)이라고 했어요). 아직이라면
정원 폴더의 `00-READ-ME-FIRST.html`을 보세요(한국어: [00-READ-ME-FIRST-KO.html](../../00-READ-ME-FIRST-KO.html)).
설치에서 가장 오래 걸리는 부분은 웹사이트 만들기(빌드)예요: 15~45분(아주 오래된 노트북이나
Pi에서는 1시간까지).

## 단계

### A 부분. 정원 열기

![내 정원의 첫 페이지](../images/website-home.png)

정원 컴퓨터에서 메뉴 `4`(또는 `http://localhost:8030`을 여세요).
*보여야 하는 것:* 내 홈 페이지, 그리고 식물이 가득한 목록(catalogue).
Windows에서는 Windows 메뉴 `4`가 안전한 터널을 통해 열어 줘요.

### B 부분. 내 비밀번호
설치가 끝날 때 이것을 제안했어요. 건너뛰었다면: 메뉴 `U`, 그다음 `5`.
웹사이트 로그인과 로그인 페이지에 함께 쓰는 비밀번호 '하나'를 정해요. 10자 이상이에요.
입력하는 동안 아무것도 보이지 않아요.

### C 부분. "비밀번호 찾기" 링크용 이메일(선택)
사이트는 Gmail의 **앱 비밀번호**(app password)로 메일을 보내요: 평소 Gmail 비밀번호가 아니라,
이 일에만 쓰는 따로 된 비밀번호예요.
1. Google 계정을 열고 **Security**(보안)에서 **2-Step Verification**(2단계 인증)을 켜세요.
2. Security에서 **App passwords**(앱 비밀번호)를 찾으세요
   (<https://myaccount.google.com/apppasswords>). 이름을 `garden`으로 하나 만드세요.
   Google은 그 비밀번호를 한 번만 보여 줘요.
3. 메뉴 `8` 설정, 그다음 `3`(이메일). Gmail 주소를 입력하고, 앱 비밀번호를 붙여 넣으세요
   (`Ctrl+Shift+V`. 화면에 보이지 않아요). 테스트 이메일에는 **y**라고 대답하세요.
*보여야 하는 것:* "Sent"(보냄), 그리고 이메일이 도착해요(처음에는 스팸함도 확인하세요).

Google의 도움말: <https://support.google.com/accounts/answer/185833>

### D 부분. AI 상자(선택)
몇몇 페이지에는 AI 도우미(식물 건강, 식물 알아보기, 이름표 읽기)가 있어요. 정원에 키를
주면 Google의 무료 Gemini 서비스를 써요.
1. <https://aistudio.google.com/apikey>에서 무료 키를 만드세요(안내서 16에서 설명해요: [16-ai-studio.md](16-ai-studio.md)).
2. 메뉴 `8` 설정, 그다음 `4`(API 키), 그다음 `1`(Gemini), 그다음 다시 `1`
   (**Paste a new key (or replace the old one)**, 새 키 붙여 넣기(또는 예전 키 바꾸기)). 키를 붙여 넣으세요: 화면에 보이지 않고,
   `.env`에 저장되고, 자동으로 테스트돼요.

키가 없으면 그 상자들은 AI가 설정되지 않았다고 말해요. 나머지는 모두 작동해요.
집 정원에는 무료 키로 충분해요. 더 쓰려고 돈을 내는 것은 본인의 선택이고, 본인의 Google
계정에서 지출 한도를 두고 해요(안내서 16, "More than the free limits"(무료 한도보다 더 쓰기)).

### E 부분. 로그인해서 식물 하나 바꾸기

![로그인 페이지(버튼 아래에 Forgot password? / First time?)](../images/website-login.png)

![전체 목록](../images/website-catalog.png)

1. `http://localhost:8030/login.php`를 열고 이름과 비밀번호로 로그인하세요.
2. `http://localhost:8030/streamlit/`에서 식물 관리(plant admin)를 여세요. 탭에서
   식물을 추가하고 편집할 수 있어요.
3. `http://localhost:8030/catalog.php`를 열고 바꾼 식물을 찾아보세요.

**Windows에서 따로 있는 정원 컴퓨터를 쓰나요?** 그러면 `http://localhost:8030/login.php` 같은
주소는 PC에서 열리지 않아요(정원은 다른 컴퓨터에 있어요). Windows 메뉴 `4`(Open the website,
웹사이트 열기)를 쓰세요. 그다음 열린 주소 끝에 `/login.php`를 붙이세요(`/streamlit/`과
`/catalog.php`도 똑같이 해요). 일하는 동안 메뉴가 연 다른 창은 그대로 두세요: 그 창이
안전한 터널이에요.

## 평소 작업(메뉴)

![메뉴(숫자나 글자를 입력하고 Enter)](../images/screen-01-main-menu.png)

| 하고 싶은 것 | 메뉴 |
|---|---|
| 정원 시작 / 멈추기 | `2` / `3` |
| 웹사이트 열기 | `4` |
| 모두 괜찮은지 확인하기 | `5` |
| 지금 백업하기 / 백업 되돌리기 | `6`, 그다음 `1` / `7` |
| 이름, 이메일, 키, 폴더 바꾸기 | `8` |
| 시간대 바꾸기(처음에는 그 컴퓨터 자신의 시간대예요) | `8`, 그다음 `2` |
| 정원 도구, 위키, n8n 켜기 또는 끄기 | `9` |
| 사람, 게스트 추가하거나 지우기, 잠그기 | `U` |
| 프로그램이 해 온 말(로그) 보기 | `M`, 그다음 `6` |

## 잘 됐는지 아는 방법
- 목록에 식물이 사진과 함께 보여요.
- 로그인해서 바꾼 내용을 저장할 수 있어요.
- 점검표(메뉴 `5`)가 0 fail(실패 0개)로 끝나요.

## 다르게 되면
| 보이는 것 | 할 일 |
|---|---|
| 페이지가 열리지 않아요 | 메뉴 `2`(시작), 그다음 메뉴 `5`. 어느 부분이 꺼져 있는지 알려 줘요. |
| 로그인에서 비밀번호가 틀렸다고 해요 | 메뉴 `U`, `5`로 다시 정하세요. 5번 틀리면 15분 기다려야 해요. |
| 비밀번호 이메일이 안 와요 | 설정, `3`, 그리고 테스트 이메일을 보내세요. Gmail이 무엇을 싫어했는지 알려 줘요. |
| 식물은 있는데 사진이 없어요 | 사진 zip을 아직 불러오지 않았어요: `junsgarden-photos-addon.zip`을 압축을 풀지 말고 홈이나 다운로드에 두고, 메뉴 `6`, 그다음 `11`(또는 `bash garden.sh photos`). 안내서 13([13-backups-and-folders.md](13-backups-and-folders.md)). |
| 그 밖의 것 | 메뉴 `H`가 도움 파일을 만들어요. 안내서 09([영어](../09-troubleshooting.md))에 해결 방법이 더 있어요. |
