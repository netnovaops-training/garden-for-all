# 26. 이름 바꾸기, 옮기기, 끄기, 정리하기

## 짧은 버전
*다 읽을 시간이 없나요? 이것이 짧은 버전이에요. 전체 안내는 아래에 있어요.*

- **파일이나 폴더 이름 바꾸기 또는 옮기기:** 메뉴 `M`, 그다음 `18`(또는 메뉴 `8`, 그다음 `8`). 그 이름을 쓰는 모든 곳이 함께 바뀌어요: 코드, 페이지, 사진 목록, 데이터베이스.
- 먼저 모든 곳을 보여 주고, 백업을 권하고, 내가 `y`를 입력하기 전에는 **아무것도** 바꾸지 않아요.
- **안내서는 옛 이름 그대로예요.** 이름을 바꾼 뒤에도 안내서에는 정원이 처음 가진 이름이 나와요. `logs/renames.tsv`에 지금 무엇이 무엇으로 불리는지 적혀 있어요(메뉴 `M`, `18`, 그다음 `4`).
- **켜기 / 끄기 스위치:** 메뉴 `M`, 그다음 `14`. **끄기**는 모두 멈추고 아무것도 지우지 않아요. **켜기**는 몇 달 뒤에도 되고, 웹사이트를 확인해요.
- **점검**은 멈춘 프로그램을 다시 시작해요. **정리**는 Docker의 남은 것만 지우고, 식물, 사진, 데이터, 캐시, 백업은 절대 지우지 않아요.
- Windows에서는 Windows 메뉴에도 같은 것이 있어요: `M`, 그다음 `20`(이름 바꾸기)과 `15`(스위치).
- 모두 AI 없는 평범한 스크립트예요: 하나에 한 가지 일만 하고, 모든 줄을 읽을 수 있어요.

---

## 왜 이름을 바꾸나요?
정원은 제작자가 붙인 이름으로 왔어요: `local/images/Gallery`, `HeroBanner`,
`privacy.html` 같은 것이요. 내 이름을 쓰고 싶을 수 있어요. 폴더 이름만 바꾸면
웹사이트가 망가져요. 코드와 데이터베이스가 아직 옛 이름을 쓰니까요. 이 도구는
**그 이름을 쓰는 모든 곳**에서 한 번에 이름을 바꿔서, 아무것도 끊어지지 않아요.

평범한 찾아 바꾸기예요. **정확한** 옛 이름(대문자까지)을, 완전한 이름일 때만 찾아요:
`Gallery`는 `Gallery2`가 아니고, `app.js`는 `app.js.map`이 아니에요. `privacy.html`처럼
짧은 페이지 이름은 `/`나 따옴표 바로 뒤에 있을 때만 세어서, 문장 속의 같은 낱말은
절대 바뀌지 않아요.

## 1. 폴더 이름 바꾸기, 한 단계씩
예: 갤러리 사진 폴더 이름을 `Gallery`에서 `Photos`로 바꿔요.

1. 메뉴 `M`, 그다음 `18`. 도구가 먼저 스스로 설명해요.

![이름 바꾸기 도구: 하는 일과 네 가지 선택](../images/screen-25-rename-menu.png)

2. `1`(웹사이트의 파일이나 폴더)을 입력하고 Enter.
3. 폴더 경로를 입력하세요: `local/images/Gallery`. 입력하면서 **Tab** 키를 누르면
   이름을 채워 줘서 오타가 없어요.
4. 새 이름을 입력하세요: `Photos`. 글자, 숫자, `-` `_` `.` 만 써요. 띄어쓰기는 안 돼요
   (웹 주소가 띄어쓰기에서 끊어져요).
5. **목록을 읽으세요.** 바꿀 줄, 사진 목록, 데이터베이스 줄을 모두 보여 줘요.
   아직 아무것도 바뀌지 않았어요.

![그 이름을 쓰는 모든 곳, 바꾸기 전에](../images/screen-26-rename-preview.png)

6. `y`를 입력하면 모두 바꿔요. 그다음 먼저 전체 백업을 하려면 `y`(추천, 몇 분).
7. 기다리세요. 프로그램을 멈추고(그래서 파일이 풀려요), 폴더 이름을 바꾸고,
   모든 곳을 바꾸고, 코드가 바뀌었으면 웹사이트를 다시 만들고(몇 분), 모두 시작하고,
   새 이름으로 사진이 열리는지 **확인**해요.

![끝: 이름을 바꾸고, 확인하고, git 기록에 저장했어요](../images/screen-27-rename-done.png)

8. 웹사이트를 열고 `Ctrl+Shift+R`을 누르세요(브라우저가 새 페이지를 가져와요).

### 바뀌는 것
| 어디 | 예 |
|---|---|
| 코드와 페이지 | `rust/`, `site/`, `beds/`, `docker-compose.yml` |
| 사진과 데이터 목록 | 갤러리의 `tags_cache.csv` |
| 데이터베이스 | 정원과 위키 표에서 그 이름을 쓰는 줄 |
| 내 설정 | `.env`의 `IMAGE_FOLDERS`: 나중에 설치해도 새 이름으로 만들어요 |
| git 기록 | 한 줄: `Renamed ... (menu M, 18)` |

무엇이든 바꾸기 전에, 바꿀 파일과 데이터베이스 줄의 사본을 모두
`logs/rename_DATE/`에 남겨요.

### 바꾸지 않는 것
그렇다고 말하고 아무것도 바꾸지 않아요:
- **프로그램 자체:** `rust/`, `beds/`, `docker/`, `garden.sh`. 바꾸면 정원이 망가져요.
- **프로그램이 만들고 이름으로 쓰는 폴더:** `local/images/plan/web`, `local/images/plan/tags`, `local/images/Database/.thumbs`, 그리고 `site/apps`(휴대폰이 앱 업데이트를 거기서 찾아요).
- **띄어쓰기나 기호가 있는 이름:** 그대로는 웹 주소에 들어갈 수 없어요.
- **다른 사진 폴더로 옮기는 사진**, 또는 다른 사진 폴더에도 같은 이름이 있는 사진: 데이터베이스는 이름만 기억해서 둘을 구별할 수 없어요.

### 되돌리기
다시 골라서 원래 이름으로 바꾸세요: 새 이름, 그다음 옛 이름. 또는
`logs/rename_DATE/`의 파일을 다시 복사하세요.

### 백업을 복원한 뒤
이름을 바꾸기 **전에** 만든 백업에는 옛 이름이 있어요. 복원(메뉴 `7`)이나 사진 파일을
다시 불러온 뒤에는 메뉴가 알아채고 이름을 다시 바꾸자고 해요. 직접 할 수도 있어요:
`bash garden.sh redo-renames`.

## 2. 큰 폴더를 다른 곳이나 다른 디스크로 옮기기
메뉴 `M`, `18`, 그다음 `2`(메뉴 `8`, 그다음 `8`, 그다음 `2`와 같아요). 예를 들어 사진을
더 큰 디스크로: `/mnt/bigdisk/garden-photos`처럼 전체 경로를 입력하세요.

- 새 위치는 **Linux 디스크**(ext4)여야 해요. Windows 디스크와 USB 디스크(NTFS,
  exFAT)는 Linux의 주인과 권한을 지키지 못해서 데이터베이스가 망가져요. 도구가
  대신 확인해요. 백업 폴더만은 어느 디스크든 괜찮아요.
- 정원을 멈추고, 폴더를 옮기고, `.env`에 새 위치를 저장하고, 다시 시작해요.

## 3. 정원 폴더 전체 옮기기
메뉴 `M`, `18`, 그다음 `3`. 예: `/mnt/bigdisk/junsgarden`.

모두 옮기고, 옮기기 전과 뒤의 파일 수를 세고, 폴더를 가리키는 것을 고쳐요:
밤 백업 일정, 자동 점검, 바탕화면 아이콘, Docker의 프로그램(새 위치에서 다시 만들어요).
옛 위치에 **이정표**(링크)를 남길지 물어요: Windows에서는 yes라고 하세요. Windows
메뉴가 거기서 정원을 찾아요. 되돌리려면 `3`을 다시 골라 옛 위치를 입력하세요:
이정표 자리에 정원이 들어가요.

메뉴가 닫히면 터미널은 아직 옛 위치에 있어요: `cd`와 새 위치를 입력하세요.

## 4. 켜기 / 끄기 스위치
메뉴 `M`, 그다음 `14`.

![스위치: 끄기, 켜기, 점검, 정리](../images/screen-28-switch.png)

- **`1` 모두 끄기.** 한동안 사이트를 운영하고 싶지 않을 때, 또는 인터넷 접속이 너무
  많을 때. `docker compose down`(`-v` **없이**)을 실행하고 현관문을 멈춰요. 식물, 사진,
  데이터, 캐시, 백업, 설정은 폴더에 그대로 있어요. 밤 백업도 쉬어요: 꺼져 있는 동안은
  바뀌는 게 없으니까요.
- **`2` 모두 다시 켜기,** 하루 뒤든 몇 달 뒤든. 모두 시작하고, 웹사이트를 기다리고,
  식물이 몇 개인지 알려 줘요. 오래 꺼져 있었으면 백업을 권해요.
- **`3` 인터넷에서만 내리기:** 집에서는 정원이 계속 돌아가요. 메뉴 `M`, `1`로 다시 인터넷에 올려요.

꺼져 있는 동안에도 **무료 No-IP 이름은 30일마다 계속 확인하세요**(No-IP가 링크를
이메일로 보내요). 안 그러면 이름이 없어져요. 자물쇠 인증서는 정원을 다시 켜면
스스로 새로 받아요.

터미널에서는: `bash garden.sh off`와 `bash garden.sh on`.

## 5. 점검
`4`는 정원의 모든 프로그램을 점검해요: 오류로 멈춘 것, "unhealthy"인 것, 계속 다시
시작하는 것은 다시 만들어서 시작해요. 웹사이트가 대답하지 않으면 다시 시작해요.
파일은 절대 지우지 않아요.

`6`은 6시간마다 스스로 점검해요(cron 한 줄, `crontab -l`로 보여요). 고친 것은
`logs/checkup.log`에 적고, 정원이 꺼져 있으면 아무것도 하지 않아요.

## 6. 정리
Docker는 프로그램의 옛 버전을 계속 남겨서, 업데이트 몇 번이면 몇 기가바이트가 될 수
있어요. `5`가 지우는 것:
- 정원 프로그램의 옛 버전(다시 만들거나 업데이트할 때마다 남는 것) 중 7일이 넘은 것,
- 30일 넘은 Docker 빌드 기록.

조심해서 쓰세요. 먼저 목록을 보여 주고 물어보며, Enter는 **아니요**예요. 정원이 쓰는
이미지는 지금 꺼져 있는 부분 것까지 모두 **남기고**, 7일이 안 된 것도 남겨요(파일을 고치고
다시 만든 뒤, 되돌아가야 할 때를 위해 옛 버전이 남아 있어요), 다른 Docker 프로젝트의 이미지는 절대 건드리지 않아요.
`docker volume prune`, `docker system prune --volumes`, `-v`가 붙은 어떤 것도 절대 쓰지 않아요.
정원이 무엇을 쓰는지 알 수 있도록 정원이 켜져 있을 때만 해요.

## 7. Windows에서: Docker를 돌리는 두 가지 방법
**이 Windows PC**에 설치하면, 설치 프로그램이 정원의 프로그램을 어떤 Docker로
돌릴지 물어요:

![2쪽: 이 PC, 그다음 Docker Desktop 또는 Ubuntu 안의 Docker](../images/wizard-2b-this-pc.png)

| | Docker Desktop(쉬운 방법) | Ubuntu 안의 Docker(직접 하는 방법) |
|---|---|---|
| 보이는 것 | 버튼이 있는 Windows 앱: 프로그램, 시작, 멈춤, 메시지 | 메뉴와 터미널 |
| 시작 | Windows와 함께 | Windows의 Ubuntu가 돌아갈 때 |
| 설치 | 설치 프로그램이 받아 주고(winget) 스위치 하나를 알려 줘요 | Windows에 더 설치할 것 없음 |
| 비용 | 개인 사용과 작은 회사는 무료 | 무료 |

Docker Desktop을 고르면 설치 프로그램이 스위치 하나를 기다려요: Docker Desktop >
Settings > Resources > WSL integration: `JunsGarden`을 **켜고**, **Apply & restart**.
그러면 정원의 프로그램이 Docker Desktop의 **Containers**에 `junsgarden`으로 보여요.

Ubuntu 안의 Docker를 골랐는데 다른 일로 Docker Desktop도 쓴다면, `JunsGarden`의 그
스위치는 **꺼 두세요**. 켜져 있으면 점검표(메뉴 `5`)가 알려 줘요.

### 오래된 Windows PC(Windows 7이나 8)
정원은 거기서 돌아가지 않고, 돌아가서도 안 돼요: Windows 7은 2020년 1월부터 보안
업데이트가 없어서 인터넷에 웹사이트를 열기에 위험하고, WSL, 기본 SSH, 최신 Docker가
없어요. 대신 좋은 방법 두 가지:
- 그 오래된 노트북에 Ubuntu를 설치하세요(Ubuntu는 오래된 컴퓨터에서도 잘 돌아가요.
  안내서 01). 먼저 파일을 USB 메모리에 복사하세요.
- 정원은 다른 컴퓨터에서 돌리고, 다른 PC나 휴대폰으로 접속하세요(안내서 20).
