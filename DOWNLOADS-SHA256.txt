How to check (in the folder where the file is):
- Windows, in PowerShell:        Get-FileHash junsgarden-for-jun.zip
  It shows "SHA256" and a long number: it must be the same as the line above.
- Ubuntu or a Raspberry Pi:      sha256sum junsgarden-for-jun.zip

More checks:
- Inside the main zip, FILES-FROM-JASON.txt lists the fingerprint of every
  file, and the garden menu checks them for you: menu M, then 11.
- The install checks the photos and wiki zips against fingerprints in this
  code before it uses them (docker/tools/photos.sha256 and
  docker/wiki/seed/wiki-pages.sha256), and refuses a file that does not match.
- Google Drive cannot scan very large files for viruses, so it shows a warning
  for the photos zip. That is normal: the fingerprint above is how you know it
  is exactly this file.
