# 준의 정원 사용법

단계마다 사진이 하나씩 있어요. 사진은 지어낸 예시 식물이 든 시험용 정원에서 찍어서, 내 식물과 이름은
다르게 보여요. 큰 사진은 컴퓨터, 작은 사진은 휴대폰이에요. 볼 곳은 주황색 테두리로 표시했어요.
(웹사이트 화면의 글은 영어예요. 버튼 이름은 영어 그대로 적고, 뜻을 함께 적었어요.)

## 1. 로그인과 비밀번호

정원은 누구나 볼 수 있어요. 식물을 더하거나 바꾸려면 로그인하세요.

1. 내 정원의 웹 주소를 여세요. 첫 페이지에 로그인 상자가 있어요. 이름(**Jun**)과 비밀번호를 넣고
   **Login**(로그인)을 누르세요. (같은 상자가 `/login.php` 페이지에도 있어요.)
   @shot 01-login
2. 로그인하면 첫 페이지에 **Welcome back, Jun!**(다시 오신 걸 환영해요)이라고 나오고, 관리 페이지가 열려요.
   @shot 03-home-signed-in
3. **비밀번호를 잊었거나 처음인가요?** 로그인 페이지에서 **Forgot password? / First time?**를 누르세요.
   이름을 넣으면 새 비밀번호를 정하는 링크가 이메일로 와요.
   @shot 02-forgot

*정원 컴퓨터에서도 언제든 정할 수 있어요: `bash garden.sh password` (메뉴에서는 U, 그다음 5).*

## 2. 관리 페이지

식물 도구는 모두 한 페이지에 탭으로 있어요: **Admin**(관리, 주소가 `/streamlit/`로 끝나요). 먼저 로그인하세요.

1. 위쪽의 탭은 저마다 한 가지 일을 해요: 식물 더하기, 고치기, 사진, 화단, 갖고 싶은 식물 목록, 바코드.
   @shot 04-admin-tabs

## 3. 식물 더하기

1. **🌱 Add Plant**(식물 더하기) 탭을 여세요. 식물의 보통 이름과 학명을 넣으세요.
   @shot 05-add-plant
2. **Enter**를 누르세요. 다음 단계가 나오고 **📋 Create Record →**(기록 만들기) 버튼이 보여요.
   @shot 06-add-plant-next
3. **📋 Create Record →**를 누르세요. 페이지가 정원에 같은 식물이 이미 있는지 확인하고(**Step 2**), 어떻게
   더할지 물어요(**Step 3**): **⚡ Quick Create**(지금은 기본만, 나머지는 나중에) 또는 **✨ AI Enrich**(무료 AI가
   자세한 내용을 채워요). 페이지 아래로 단계를 따라가세요. 마지막 버튼이 식물을 저장하고, 식물이 목록에 나와요.
   @shot 06b-add-plant-saved

## 4. 식물 고치기

1. **✍️ Manual Editor**(직접 고치기) 탭을 열고, 위의 목록에서 식물을 고르세요.
2. 바꾸고 싶은 것(예: 회사, 화단, 좋아하는 햇빛)을 바꾸고 맨 아래 **Save**(저장)를 누르세요.
   @shot 07-edit-plant

## 5. 식물 빼기 (죽었거나 남에게 줬을 때)

정원은 식물의 기록과 그동안의 일을 그대로 두고, 이제 없다는 것만 기록해요.

1. **Full Catalog**(전체 목록)에서 식물을 눌러 창을 여세요.
   @shot 08-plant-window
2. **✏️ Edit**(고치기)를 누르세요. 양식 아래의 초록 상자에서 **🗑️ Removed**(뺐음) 또는 **💀 Died**(죽었음),
   몇 개인지 고르고 저장하세요.
   @shot 09-remove-plant

## 6. 사진

1. 식물에 사진을 넣거나 바꾸려면: 관리 탭 **📸 Manual Image Replace**(사진 바꾸기). 식물을 고르고, 컴퓨터나
   휴대폰에서 사진을 골라 저장하세요. **🗑️ Remove this image**(이 사진 빼기)로 사진을 뺄 수 있어요.
   @shot 10-photos-admin
2. **Gallery**(사진첩) 페이지는 모두에게 정원 사진을 보여 줘요.
   @shot 11-gallery

## 7. 화단과 화단 이름표 (QR 코드)

1. **🗺️ Bed Assignment**(화단 정하기, 관리 탭)에서 식물을 화단에 넣어요: 식물마다 화단을 고르고 저장하세요.
   @shot 12-beds
2. **이름표**: 로그인하고 `/labels`를 여세요. 화단마다, 살아 있는 식물마다 QR 코드가 있는 이름표가 있어요.
   페이지를 인쇄해서 잘라 쓰세요. 이름표를 스캔하면 웹사이트에서 그 식물이나 화단이 열려요.
   @shot 13-labels

*화단 이름을 바꾸거나 정원의 웹 주소를 바꿔도 코드는 계속 작동해요.*

## 8. 댓글과 방명록

1. **방명록**: 첫 페이지 아래쪽에서 누구나 짧은 글을 남길 수 있어요.
   @shot 14-guestbook
2. **식물 댓글**: 식물 창에서 사진을 누르세요. 큰 사진 아래에 댓글과 댓글을 쓰는 상자가 있어요. 누가 댓글을
   남기면 관리 페이지에 작은 종이 떠요.
   @shot 15-plant-comments

## 9. 찾기

1. **Quick Search**(빠른 찾기): 이름의 일부를 넣으면, 치는 동안 맞는 식물이 나와요.
   @shot 16-quick-search
2. **Full Catalog**(전체 목록): 위의 찾기 상자가 카드를 걸러 줘요. 글자 버튼과 화단 버튼으로도 좁힐 수 있어요.
   @shot 17-catalog-search

## 10. 휴대폰 앱

1. 컴퓨터에서 `/app/setup`을 여세요. 코드가 두 개 있어요.
   @shot 18-app-setup
2. 휴대폰으로 **첫 번째** 코드를 스캔하세요: 앱을 내려받아요. 설치하세요(처음에는 Android가 브라우저에서
   설치해도 되는지 물어요: 허용하세요).
3. **두 번째** 코드를 스캔하세요: 앱이 내 정원의 주소를 배워요. 화면 아래에 그렇게 나와요.
4. 앱을 여세요. 정원 이름과 비밀번호로 로그인하거나, **손님으로 계속하기**를 눌러 둘러보세요.
   @app 07-ko-1-sign-in
5. 목록: 위에 찾기, 그 아래 화단, 그다음 식물들. 식물을 누르면 열려요.
   @app 07-ko-2-catalogue
6. 식물: 사진, 묶어서 보여 주는 정보, 메모. **‹ 목록**을 누르면 돌아가요.
   @app 07-ko-3-plant
7. 아래쪽(로그인했을 때): **알아보기**(식물 사진), **이름표**(식물 이름표 사진), **바코드**(바코드 사진),
   **영수증**(영수증 사진).
8. 새 버전이 나오면 앱이 **업데이트**를 권해요.

*앱은 영어와 한국어로 말해요. 휴대폰의 언어를 따라가고, 이 앱만 따로 고를 수도 있어요: 설정, 애플리케이션,
준의 정원, 언어.*

## 11. 정원의 웹 주소 바꾸기

한 번에 모두 바뀌어요: 정원이 쓰는 주소, 이름표, 휴대폰 앱. 예전 주소는 계속 새 주소로 넘겨줘서, 인쇄한
이름표와 예전 휴대폰도 계속 작동해요. 먼저 새 이름을 내 No-IP 계정에 더하세요.

1. 로그인하고 `/labels`를 여세요. **Web address / 웹 주소**에 새 웹 이름(원하면 폴더도)을 넣고
   **Change the address / 주소 바꾸기**를 누르세요. 1분 안에 바뀌었다고 페이지에 나와요.
   @shot 19-address
2. 또는 정원 컴퓨터에서: `bash garden.sh webname new.name.org` (메뉴: M, 그다음 16), 또는 Windows 설치
   마법사의 마지막 페이지: **Change the web address / 웹 주소 바꾸기**.
