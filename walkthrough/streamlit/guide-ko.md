# 로컬 식물 AI로 식물 추가하기

*준의 정원, 식물 관리 화면(`/streamlit/`). 모든 사진은 지어낸 견본 식물이 있는 시험용 정원에서 찍었어요.
사진 속 AI의 답은 미리 녹화해 둔 견본 실행이에요.*

<div class="note" markdown="1">

**AI가 돌아가는 곳.** 새 식물을 채우는 AI는 **12GB 이상의 NVIDIA 그래픽 카드가 있는 Windows PC**(예: RTX
4070 Ti)에서만 돌아가요. Windows 설치 마법사(CUSTOM, '로컬 식물 AI')나, 나중에 Windows 메뉴 More, 22에서
설정해요. 웹사이트는 다른 컴퓨터, 예를 들어 노트북에서 돌아가도 돼요: PC가 1분마다 집 네트워크를 통해
웹사이트에 일을 물어봐요. 두 컴퓨터 모두 새로 여는 것이 없어요. PC가 꺼져 있으면 새 식물은 대기열에서
기다리다가, PC가 다시 켜지면 채워져요.

</div>

## 1. 식물 추가: 칸 여섯 개

식물 관리 화면을 여세요. 첫 번째 탭 **🌱 식물 추가**는 여섯 가지만 물어봐요:

- **속**: 학명의 첫 단어, 예: *Salvia*.
- **종**: 두 번째 단어, 예: *nemorosa* (교배종이면 *hybrid*, 모르면 비워 두세요).
- **이름**: 이름표에 쓰인 이름.
- **화단**, **수량**, **개당 가격**.

**나머지는 데스크톱 AI가 채우게 하기**는 체크한 채로 두고 **➕ 식물 추가**를 누르세요. 식물은 바로
저장되고, 나머지는 AI가 채워요.

@shot 01-add-form

## 2. AI가 채우는 것 지켜보기

페이지의 **AI가 작업 중인 식물**에 그 식물이 막대와 함께 나오고, **검토** 아래에도 같은 막대가 있어요.
*데스크톱 도우미를 기다리는 중* → *웹에서 찾는 중* → *정보 채우는 중 (phi4)* → *사진 찾는 중* →
*모든 값을 확인하는 중 (gemma)* → *검토할 준비가 됐어요* 순서로 가요. AI가 일하는 동안 페이지는 저절로
새로 고쳐져요. 닫았다가 나중에 다시 와도 돼요.

@shot 02-queued

PC에서 일어나는 일: 도우미가 이 식물의 재배 회사 페이지와 믿을 만한 정원 페이지(대학 지도소, 식물원)를
세 개까지 찾고, 예의 바르게 읽고(페이지 사이에 몇 초씩), 페이지에 적힌 칸을 모두 채우고, 사진을 5장까지
찾아요. 그다음 두 번째 모델이 모든 값을 그 값이 나온 문장과 대조해 확인해요.

@shot 05-filling

## 3. 검토: 채운 것, 검토 필요, 아직 비어 있음

답이 들어오면 같은 페이지에 검토가 나와요:

- **확인 결과**: 한 줄 판정 (*맞아 보여요* 또는 *확인이 필요해요*).
- **출처**: 정보가 나온 재배 회사 페이지 (식물과 함께 저장돼요).
- **찾은 사진**: 최대 5장, 각각 `.webp` 사진 하나로 저장돼요. 아래 작은 줄에 어디서 왔는지 나와요.

@shot 07-review

- **AI가 채운 것**: 쓴 값마다, 그렇게 적힌 페이지의 문장과 그 페이지로 가는 ↗ 링크가 있어요. AI는 **빈**
  칸만 채워요. 내가 입력한 값은 절대 바꾸지 않아요. 바꾸기 전마다 식물의 사본을 남겨요.

@shot 08-filled

- **검토 필요**: 확인하지 못한 값이에요. 이 값들은 **쓰지 않았어요**. 맞다고 생각하는 것을 체크하고
  **체크한 값 쓰기**를 누르세요 (빈 칸만 체크할 수 있어요).

@shot 09-needs-review

## 4. 아직 비어 있는 것: 내 Claude에게 물어보기

**아직 비어 있음**에 아직 빈 칸이 나와요. **📤 아직 비어 있는 것 내보내기**를 누르면, 그 칸들과 칸마다
허용되는 값, 바로 쓸 수 있는 프롬프트(영어와 한국어)만 담은 작은 파일을 받아요. 이 파일을 내 Claude에게
주세요. 답(JSON 목록)을 `.json` 파일로 저장해서 **⚙️ 고급 → 🔄 JSON Pipeline → 📥 Import & Review**로
가져오세요 (8단계). 저장하기 전에 모든 값을 보여 줘요.

@shot 10-missing

파일에 들어 있는 프롬프트:

```
정원 식물 데이터베이스를 채우는 일을 도와주세요. 아래 파일에는 식물마다 아직 비어 있는 칸만,
허용되는 값과 형식과 함께 들어 있어요. 규칙: 1) 답은 JSON 배열(맨 바깥이 [ ... ])만 쓰고 ...
2) 그 식물에 적힌 빈 칸만 넣고, 다른 칸은 절대 더하거나 바꾸지 마세요. 3) "allowed" 값이 있는 칸은
그중 하나를 글자 그대로 쓰세요 ... 5) 확실하지 않으면 빼세요: 틀린 값보다 빈 칸이 나아요.
```

## 5. 승인

검토 맨 아래에 **✅ 승인**이 있어요. 식물이 맞아 보이면 누르세요. **정원 주인**(준)만 승인할 수 있어요.
로그인한 다른 사람에게는 누가 승인할 수 있는지 보여요.

@shot 11-approve

@shot 13-approved

## 6. 영수증

**🧾 영수증** 탭은 영수증을 식물과 함께 보관해요: 식물을 고르고 (가장 새 식물이 맨 위), 가게, 날짜,
가격을 입력하고, 영수증 사진이나 PDF를 골라 **💾 영수증 저장**을 누르세요. 영수증은 비공개예요: 공개
웹사이트에 절대 나오지 않아요.

@shot 14-receipt

그 식물에 보관한 영수증은 양식 아래에 **열기** 링크와 함께 나와요.

@shot 15-receipt-saved

## 7. 사진

**🖼️ 사진** 탭에서 내 사진을 추가해요: 식물을 고르고, 사진을 한 장 또는 여러 장 고르고, **➕ 사진 추가**를
누르세요. 사진마다 최대 2000픽셀의 `.webp` 하나로 보관해요 (작은 사본은 만들지 않아요). 500픽셀보다 작은
사진은 쓰지 않아요. 첫 번째 사진이 대표 사진이에요. 사진을 지우거나 순서를 바꾸려면 *Manual Image
Replace*를 쓰세요.

@shot 16-pictures

@shot 17-pictures-added

## 8. 고급: JSON 가져오기와 다른 도구

JSON 가져오기는 그대로 있고, 이제 탭 아래 **⚙️ 고급**에 있어요. 고급에는 클라우드 AI 탭과 전체 식물 추가
양식도 있어요. 4단계의 답을 가져올 때만 필요해요.

@shot 18-advanced

## 9. 데스크톱 도우미의 키

PC가 웹사이트와 이야기하려면 키가 필요해요. 식물 추가 탭에서 **🖥️ 데스크톱 도우미**를 열고, PC 이름을
입력하고 **🔑 도우미 키 만들기**를 누르세요. 키는 **한 번만** 보여요: Windows 설치 마법사의 로컬 식물 AI
페이지(또는 Windows 메뉴 More, 22)에 붙여 넣으세요. 목록에 키마다 마지막으로 쓴 때가 나오고, **끄기**를
누르면 그 키는 바로 멈춰요.

@desk 03-helper-box

## 알아 두면 좋은 것

- 언어: 옆 메뉴의 **English · 한국어** 링크로 새 탭의 언어를 바꿔요.
- AI는 내가 입력한 값을 절대 바꾸지 않고, 확인되지 않은 것은 쓰지 않으며, 바꾸기 전마다 식물의 사본을
  남겨요.
- 노트북만 있어도 (Windows PC 없이) 돼요: 식물은 저장되고 대기열에서 기다려요. *Manual Editor*에서 직접
  채우거나 4단계로 채울 수 있어요.
- 궁금한 것은 제작자에게 물어보세요.
