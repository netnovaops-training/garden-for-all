Jun's Garden

내 웹사이트, 내 컴퓨터, 내가 관리해요. 이 페이지를 먼저 읽어 주세요. 5분 걸려요.

이것은 무엇인가요: 정원 웹사이트 전체(식물, 사진, 블로그, 위키, 정원 도구 전부)와, 그것을 설치하고 돌보는 것을 도와주는 메뉴 프로그램이에요. 메뉴는 모든 단계를 하기 전에 설명하고, 실행할 명령을 그대로 보여 주고, 모든 내용을 읽을 수 있는 logs 폴더에 저장해요. 다른 사람에게 내 컴퓨터에 들어오는 권한을 주는 것은 하나도 없어요.

설치되는 프로그램 전체 목록과 공식 페이지 링크: WHAT-GETS-INSTALLED.ko.md (영어: WHAT-GETS-INSTALLED.md). 각 프로그램을 고른 이유: WHY-THESE-PROGRAMS.ko.md (영어: WHY-THESE-PROGRAMS.md).

전체 과정을 한 페이지에: 모든 것이 어떻게 작동하나요(설치, Easy와 Custom, 모든 기능의 지도).

시작하기 전에

놀랄 일이 없도록: 시작하기 전에가 필요한 모든 것을 꼭 필요한 것과 선택으로 나눠서 보여 줘요(가입할 곳, 키, 포트, 적어 둘 이름과 주소). 각각 얼마나 걸리는지도 있어요. Easy와 Custom도 설명해요. 모든 안내서는 짧은 버전(Quick version)으로 시작해요.

  • 정원 서버가 될 컴퓨터 한 대. 계속 켜 둘 수 있어야 해요: Ubuntu 노트북(추천), Raspberry Pi, 또는 데스크톱. 안내서 01에서 오래된 노트북을 Ubuntu 컴퓨터로 바꾸는 방법을 볼 수 있어요.
  • 그 컴퓨터의 인터넷 연결(랜선이 가장 안정적이에요).
  • 그 컴퓨터에 디스크 빈 공간 약 60 GB(Windows에서는 C:에 약 60 GB).
  • 약 1~2시간. 대부분은 웹사이트가 만들어지는 동안 기다리는 시간이에요(15~45분. 아주 오래된 노트북이나 Pi에서는 1시간까지).
  • 그 컴퓨터의 본인 비밀번호. Ubuntu가 가끔 물어봐요.
  • 오늘이 아니라 나중에: 무료 Gmail 앱 비밀번호(이메일용)와 무료 No-IP 계정(사이트를 인터넷에 올리기용). 그 단계가 되면 메뉴가 둘 다 설명해 줘요.

내 웹 이름: 그대로 쓰거나, 새 이름 고르기

인터넷에서 정원의 주소는 웹 이름이에요. 처음 이름은 junsgarden.zapto.org예요. 설치를 시작할 때 한 번 물어봐요:

  • junsgarden.zapto.org 그대로 쓰기(추천), 또는
  • 새 이름 고르기(예: 어머니 정원을 위한 이름). 웹사이트 이름 바꾸기가 그 이름을 쓰는 모든 파일에 새 이름을 넣어요. https://, www., / 뒤의 모든 것은 알아서 빼 주고, 바꾸는 파일마다 사본을 남기고, 나중에 다시 할 수도 있어요(메뉴 M, 16; Windows에서는: More, 17).

웹 이름 얻기는 무료이고 약 5분 걸려요: No-IP에 계정을 만들고, Dynamic DNS, No-IP Hostnames, Create Hostname. 무료 계정은 이름이 하나이고, 30일마다 No-IP가 확인 링크를 이메일로 보내 줘요(안내서 04, A 부분). 이름은 지금 고르고, 인터넷에 올리기 전 아무 때나 No-IP에 추가해도 돼요.

나중에 원하면: 무료 DuckDNS 이름으로 다른 것들에게 각자의 주소를 줄 수 있어요 (예: Home Assistant 패널이나 자동화). 모두 내 로그인 페이지 뒤에 있고, 여전히 공유기 포트 두 개만 써요. 안내서 04, "고급". 오늘 정할 필요는 없어요.

설치하기, 한 단계씩

지금 이 페이지를 읽고 있는 컴퓨터를 고르세요:

1

Google Drive에서 정원 다운로드하기

받은 Google Drive 링크를 여세요. 폴더에 내려받을 파일이 세 개 있어요:
파일무엇필요한가요?
junsgarden-for-jun.zip내 식물, 안내서(handbook), 시작 파일(약 5 MB). 프로그램 자체는 처음 시작할 때 GitHub에서 가져와요네
junsgarden-photos-addon.zip정원 사진 전부(약 800 MB)사진을 보려면. 직접 내려받는 것은 선택이에요. 설치가 사진을 알아서 받아요(작은 조각을 여러 곳에서 동시에 받고, 주 zip 안의 열쇠 photos.key로 열어요). 아니면 이 zip을 직접 두어도 돼요. 언제든 다시 받을 수 있어요(메뉴 6, 그다음 11)
junsgarden-wiki-addon.zip위키 페이지(1 MB 미만)위키를 원할 때만
한 번에 파일 하나씩 내려받으세요: 파일 하나를 누르고 Download(위쪽의 화살표)를 누르세요. (여러 파일을 한꺼번에 고르면, Drive가 그것들을 drive-download-...zip이라는 파일 하나로 묶어 버려요.) 큰 파일은 Google이 "can't scan this file for viruses"(바이러스 검사를 할 수 없어요)라고 해요: Download anyway(그래도 다운로드)를 누르세요.
어디에 둘까요: 파일은 Downloads(다운로드) 폴더에 들어와요. Files(파일)를 열고 Downloads로 가서, 파일을 하나씩 왼쪽 줄의 Home(홈)으로 끌어다 놓으세요.파일 탐색기(File Explorer)를 열고 Downloads(다운로드)로 가서, 파일을 하나씩 왼쪽 줄의 Desktop(바탕 화면)으로 끌어다 놓으세요 (바탕 화면이 OneDrive 안에 있어도 괜찮아요). 설치 프로그램은 사진 zip과 위키 zip을 바탕 화면에서 찾아요. Downloads에 그대로 두어도 거기서 찾아요. 정원 폴더가 OneDrive 안에 있게 되면, 설치 프로그램이 폴더를 OneDrive 밖으로 옮겨 주겠다고 해요(시작하기 전에, "바탕 화면이 OneDrive 안에 있다면"). 사진과 위키 zip은 압축을 풀지 마세요: 설치가 찾아서 지문을 확인하고 모두 합쳐 줘요. 여분의 사본을 원하나요? 백업 메뉴가 내려받은 파일을 NAS에 둘 수 있어요(메뉴 6, 그다음 12).
2

첫 번째 파일만 압축 풀기

Files(파일)를 열고 Home(홈)으로 가서 junsgarden-for-jun.zip을 오른쪽 클릭하고 Extract Here(여기에 풀기)를 고르세요. Home에 junsgarden-for-jun 폴더가 새로 생겨요.
바탕 화면에서 junsgarden-for-jun.zip을 오른쪽 클릭하고 Extract All(모두 압축 풀기)을 고르세요. Windows는 zip 이름을 딴 폴더를 제안해서, junsgarden-for-jun\junsgarden-for-jun이 돼 버려요. 압축 풀기 창에서 경로의 마지막 부분을 지워서 \Desktop으로 끝나게 한 다음, Extract(압축 풀기)를 누르세요. 바탕 화면에 junsgarden-for-jun 폴더가 새로 생겨요. (벌써 다른 방법으로 풀었다면: 그 안에 있는 junsgarden-for-jun 폴더를 열어서 그것을 쓰세요.)
3

메뉴 시작하기

처음에는 프로그램 자체를 GitHub에서 가져와요(약 75 MB라서 인터넷이 필요해요). 그리고 zip에 들어 있던 목록과 모든 파일을 비교해서 확인해요. 처음 한 번만 1~2분 걸려요. Google Drive의 zip에는 GitHub에 없는 것만 들어 있어요: 내 식물, 음악, 안내서(handbook), 작은 시작 파일.
junsgarden-for-jun 폴더를 여세요. Start-Here-Ubuntu.sh를 오른쪽 클릭하고 Run as a Program(프로그램으로 실행)을 고르세요. 터미널 창이 메뉴와 함께 열려요.
"Run as a Program"이 없나요? 폴더의 빈 곳을 오른쪽 클릭하고 Open in Terminal(터미널에서 열기)을 고른 다음, 이것을 붙여 넣고(터미널에서는 Ctrl+Shift+V로 붙여 넣어요) Enter를 누르세요:
bash Start-Here-Ubuntu.sh
또는 아무 터미널이나 열고(Ctrl+Alt+T) 이것을 붙여 넣으세요. 어느 위치에서나 작동해요:
bash ~/junsgarden-for-jun/Start-Here-Ubuntu.sh
압축을 푼 junsgarden-for-jun 폴더를 열고 Start-Here-Windows.cmd를 더블클릭하세요. Windows가 "Windows protected your PC"(Windows의 PC 보호)라고 하면 More info(추가 정보)를 누르고, 그다음 Run anyway(실행)를 누르세요 (이 파일은 일반 텍스트 파일이라서 먼저 메모장으로 열어 읽어 볼 수 있어요). 설치 마법사(setup wizard)가 열려요: 왼쪽에 내 단계, 아래에 Help(도움말), Back(뒤로), Next(다음)가 있어요. 먼저 EASY(자동, 추천) 또는 CUSTOM(한 쪽씩 내가 골라요: 안내서 23)을 고르세요.
설치 마법사는 영어로 나와요. 첫 쪽에서 한국어를 고르면, Help 버튼과 #낱말이 한국어 안내서를 열고 검은 창도 한국어로 나와요. 나중에 메뉴 L에서 바꿀 수 있어요.
정원은 항상 Ubuntu에서 실행돼요. 설치 프로그램이 어디에서 실행할지 물어봐요:
• 집에 있는 다른 컴퓨터(Ubuntu 노트북 또는 Raspberry Pi, 추천): 그 컴퓨터의 로컬 IP 주소(그 컴퓨터에서 hostname -I를 입력하세요. 192.168.1.50처럼 생겼어요. 또는 Find it for me(찾아 줘요)를 눌러 목록에서 고르세요)와 그 컴퓨터의 사용자 이름을 입력해요. 설치 프로그램이 모든 것을 그쪽으로 복사하고 거기에 설치해요. 그 컴퓨터에는 SSH 서버가 한 번 필요해요:
sudo apt install -y openssh-server
• 이 Windows PC: Windows가 자기만의 Ubuntu(WSL, Microsoft가 만든 것)를 설치하고, 정원은 그 안에서 실행돼요. 여기서 정원은 이 PC 자신에서 쓰는 용도예요. 인터넷에 올리는 것, 그리고 집에 있는 휴대폰과 다른 컴퓨터에 보여 주는 것은 따로 있는 정원 컴퓨터(Ubuntu 노트북 또는 Pi)가 필요해요: Windows 안의 Ubuntu는 PC 안에 자기만의 내부 주소가 있어서, 공유기와 휴대폰이 닿을 수 없어요. (더 알고 싶다면: WSL 네트워크, Microsoft. 정원은 이것을 설정하지 않아요.)
그다음 정원의 프로그램을 어떤 Docker로 돌릴지 물어요: Docker Desktop은 쉬운 방법이에요(버튼으로 보고, 시작하고, 멈춰요. 설치 프로그램이 대신 받아 줘요). Ubuntu 안의 Docker는 직접 하는 방법이에요. 안내서 26에서 둘을 비교해요.

이 Windows PC를 고르면, 처음에는 이렇게 진행돼요:

  • Windows가 WSL을 켜도 되는지 허락을 물어요(Yes(예)를 누르세요). 그다음 다시 시작이 한 번 필요해요. 다시 시작한 뒤 Start-Here-Windows.cmd를 다시 더블클릭하고 같은 페이지를 넘기세요: 이어서 해요.
  • 그다음 WSL용 Ubuntu를 내려받아요(수백 MB).
  • Ubuntu 사용자 이름(예: jun)과 비밀번호를 정하라고 해요. 비밀번호는 두 번 입력해요(입력하는 동안 아무것도 보이지 않아요). 적어 두세요. 바로 뒤에 그 비밀번호를 다시 물어봐요.
  • 다시 시작한 뒤 WSL이 시작되지 않으면, PC의 BIOS에서 가상화(virtualization)를 켜야 할 수 있어요: Microsoft의 WSL 문제 해결.
  • PC가 절전 모드로 들어가면 안 돼요. 그러면 정원이 멈춰요: Settings(설정), System(시스템), Power(전원), Sleep(절전) = Never(안 함).
  • C:에 빈 공간이 약 60 GB 필요해요.

검은 창. Install(설치) 페이지에서 Start the install(설치 시작)을 누르면 검은 창이 열려요. 진짜 일은 그 창이 하고, 질문도 거기서 해요(EASY 또는 CUSTOM은 마법사에서 이미 골랐어요). 마지막에 EASY가 물어봐요: Login name [Jun](그냥 Enter를 누르세요), 그다음 새 비밀번호(입력하는 동안 아무것도 보이지 않아요), 그다음 Set up email (Gmail) now, for 'forgot password' links? (y/N)(Enter는 no예요. 그러면 Are you sure? ... Skip email for now? (Y/n)라고 다시 묻고, Enter를 누르면 건너뛰어요. 나중에 메뉴 8, 그다음 3으로 추가할 수 있어요), 그다음 Add your Google Gemini key (AI Studio) now? (Y/n)(Enter는 yes예요. 붙여 넣는 곳에서 아무것도 넣지 않고 Enter를 누르면 건너뛰어요. 나중에 메뉴 K로 추가할 수 있어요), 그다음 OpenRouter 키에 대한 같은 질문(Enter는 no예요). EASY install finished(EASY 설치 끝)라고 할 때까지 검은 창을 열어 두세요. 그다음에는 닫아도 돼요. 설치 마법사의 마지막 페이지는 비밀번호와 키가 끝난 뒤에만 나와요.

그 뒤 평소 작업은 Garden-Menu-Windows.cmd를 더블클릭하세요(Ubuntu와 같은 메뉴예요).
4

설치 프로그램이 정원을 어디에서 실행할지(이 컴퓨터, 또는 IP 주소로 다른 컴퓨터) 묻고, 그다음 EASY 또는 CUSTOM을 물어봐요. 1 EASY(쉬운 설치)를 고르세요: 정원에 필요한 모든 것과 정원 도구를 대신 골라 줘요. 이름, 이메일, 비밀번호만 입력하면 돼요. 위키는 들어 있지 않아요: 원할 때만 나중에 추가하세요(메뉴 9, Parts). 위키 페이지는 따로 내려받는 junsgarden-wiki-addon.zip에 있어요. 정원을 인터넷에 올리기(나중에)

정원이 집에서 잘 작동하면, 메뉴 M 그다음 1(정문)이 해 줘요. 첫 번째 선택 "아직 인터넷에 없음"은 집 Wi-Fi에 있는 휴대폰과 컴퓨터에만 정원을 보여 줘요. 인터넷(www)에 올릴 준비가 되면, 선택 3이 No-IP 업데이트 프로그램(DUC)도 설치해요. 이 프로그램이 웹 이름이 계속 정원 컴퓨터를 가리키게 해요.

Windows PC 안의 Ubuntu(WSL)에서 정원을 돌리고 있나요? 그러면 여기 적힌 대로 되지 않아요: Windows 안의 Ubuntu는 PC 안에 자기만의 내부 주소가 있어서, 공유기와 휴대폰이 닿을 수 없어요. 그 PC에서 정원은 PC 자신에서 쓰는 용도예요. 정원을 인터넷에 올리는 것, 그리고 집에 있는 다른 기기에 보여 주는 것은 따로 있는 정원 컴퓨터(Ubuntu 노트북 또는 Pi)가 필요해요. 더 알고 싶다면: WSL 네트워크, Microsoft(정원은 이것을 설정하지 않아요).

필요한 것:

  • 본인의 무료 No-IP 계정과 그 안의 내 웹 이름(junsgarden.zapto.org, 또는 고른 이름), 그리고 그 이름의 DDNS 키 (안내서 04에서 누를 곳을 보여 줘요).
  • 공유기에서 정원 컴퓨터의 주소를 예약하기(안내서 14).
  • 공유기에서: TCP 포트 80과 443만 그 주소 하나로 전달(forward)하세요. 다른 것은 하지 마세요.

먼저 .test로 끝나는 지어낸 이름으로 연습할 수 있어요: 모든 것이 정원 컴퓨터에서만 작동하고, 인터넷에서는 아무것도 바뀌지 않아요.
